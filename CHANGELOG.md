# intellij-bluloco-dark-theme Changelog

## [Unreleased]

## [2026.1.0] - 2026-08-21

### Added

- Added Bluloco Midnight, a deeper and quieter alternative for users who prefer a lower-glare workspace
- Added Bluloco accent colors to action, file-type, object, and checkbox icons
- Added side-by-side previews of Dark and Midnight across the editor, tool windows, completion, settings, and diff views

### Improved

- Redesigned both themes for the IntelliJ Islands UI, with clearer separation between editors, tool windows, popups, and navigation
- Made the active editor tab and current work area easier to identify
- Refined rounded surfaces, spacing, borders, and compact-mode sizing to feel native in current IntelliJ IDEs
- Reduced the intensity of selections and notifications so they remain visible without distracting from code
- Improved the contrast of secondary, muted, and disabled text throughout the IDE
- Harmonized editor colors across Dark and Midnight while preserving the distinctive Bluloco syntax palette
- Refined colors for completion popups, settings, terminal output, VCS states, and diff views

### Compatibility

- Now requires IntelliJ Platform 2025.2.3 or newer to provide the full Islands experience

## [1.0.1]

### Improved

- Minor fixes and improvements

## [1.0.0]

### Added

- Initial commercial release of Bluloco Dark Theme for IntelliJ-based IDEs
- Comprehensive syntax highlighting for Java, Kotlin, Python, JavaScript, TypeScript, HTML, CSS, JSON, YAML, Markdown, SQL, and more
- Full UI theming for all IntelliJ IDE components
- Carefully mapped ANSI terminal colors
- Git and VCS status colors
- Diff viewer colors
